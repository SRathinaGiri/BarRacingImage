## Alternative Short Summary

## Description

Bar Racing Image is a Microsoft Power BI custom visual for animated bar race charts. It compares ranked categories across a play axis and can display category images supplied as report data.

Use it to show changes over time, cumulative totals, popularity trends, leaderboards, and other time-based rankings. The visual includes configurable animation speed, category image placement, data labels, axis labels, play controls, and a current play-axis label.
